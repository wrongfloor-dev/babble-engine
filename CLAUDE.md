# Babble Engine

Gibberish / fictional speech generator for games. Plain HTML + vanilla JS, no build step, no dependencies.

## Layout
Everything that goes online lives in `site/` (Cloudflare Workers static assets, `wrangler.jsonc`). `dossier/`, `metingen/`, `tests/` and this file stay out.
- `site/index.html` – markup for all views (make, my voices, studio steps 1–3, dialogs)
- `site/src/styles.css` – design tokens and styles. Look (redesign D, 2026-10-25): warm paper and ink outlines with a hard shadow, light by default with a dark variant; per style `body.e-*` sets `--accL/--accD` (accent, 5:1 or more with its text colour) and `--tintL/--tintD` (stage); Figtree UI font, Bagel Fat One for the logo, names and panel headings. Make screen: style cards with a mini critter (`MINI` in app.js), voices, then line and stage side by side at one height, player strip fixed at the bottom of the stage, settings below (this voice / all styles). Fonts are self-hosted in `site/fonts/` (woff2, SIL OFL; license files next to them)
- `site/src/engine.js` – all audio synthesis and analysis, no DOM. One source for the tool and the web module: loads as a plain script (global `Babble`), as CommonJS (`module.exports` at the bottom) and from `babble.mjs`.
  - `tokenize`, `prosody`, `renderSynth` (formant synthesis), `renderSample` (own-voice playback), `renderTone` (Soft Tones + Talking Instruments)
  - Bloopa Doopa (2026-10-26, replaced the Simlish-like Vemmo; internal id stays `vemmo` so links, characters and `style: 'vemmo'` keep working): the cartoon language of De Workshopbende, after its language guide v3. `INTENTS` (per intent: onsets, endings, tricks jump/rhyme/sing/plain, closer chance, interjections, anchors), `ANCHORS` (7 fixed words with their melody `mel`), `vemmoClip`, `bloopaWord`. Word filter `NOWORD` + `BADPART` (Dutch and known English words, rude words, other characters' catchphrases). Clusters (bl, pl, fl, kl, kr) are two consonants in `buildPhones`; with an own voice `pickGrain` uses the first. Tempo ×1.25 in `styleOpts`. Lengths: short about 0.5–1.2 s, medium 1–2.5 s (Bram slower on purpose). Other styles bit-identical (396 fingerprints).
  - Extra voice styles: `PALETTES` + `paletteLang` (Grumble, Gizmo, Sprite, Spooky Whisper, Babytalk), `babyfy`, `postFX` (grumble, gizmo, sprite, radio)
  - Styles added in 1.2.0 (2026-10-26): Name Talk (`nameSyls`, `nameTalk`, option `name`), Grunts & Barks (`BARKS`, `barkToks`, tokens carry `mel` + `hold`), Spooky Whisper (`ghostFX`: syllables reversed + reverb), Text Blips (`renderBlips`), Droid Chirps (`renderDroid`), Kazoo (a `renderTone` kind in Talking Instruments). `textToks` is the one text-to-syllables step for the tool, the studio preview and the module. All other styles stayed bit-identical (396 fingerprinted renders).
  - Styles and voices (2026-10-25, moved from app.js): `EMETA`, `ENGINE_ORDER`, `ENGINES`, `FX`, `wetFor`, `roomIR`. `styleOpts` + `renderStyle` are the render path (Echo Folk mixes four renders there); app.js `opts()`/`render()` call them. Moved bit-identical: 94 reference renders matched.
  - Seed: every noise call goes through `RND` (Math.random by default). `Babble.render` swaps in a seeded generator for one call, so the tool's sound is unchanged.
  - Web module API (`Babble`, version `BABBLE_VERSION` = `package.json`): `render(text, options)` → `{pcm, sampleRate, duration, syllables, style, voice}`, `toWav`, `play` (browser, with room), `styles`, `loadVoice`. Own voice (1.1.0, 2026-10-26): the Export button in Voices & characters downloads `<name>.babble-voice.json` (`voiceToFile`: every grain as base64 16-bit PCM plus its labels `c v pos f0 loud`, and the recording sample rate); `loadVoice` reads it, render option `ownVoice` (+ `steady`) uses it, `grainsAt` resamples to the render rate. Checked: module render of an exported voice matches the app within 16-bit rounding. English mood names map to the Dutch keys in `MOODS` (`MOOD_ALIAS`). `site/src/babble.mjs` re-exports it as an ES module, `site/src/engine.d.ts` has the types, `package.json` lets people `npm i github:wrongfloor-dev/babble-engine`. Docs: `README.md`.
  - Studio: `buildScript`, `studioSchedule`, `analyzeScriptRecording`, `splitChunk`, `estimateF0`, `makeAmbient`
  - Recording rounds (2026-10-25): `basis` (every consonant × a/e/i/o/u, 23 lines, 92 sounds, ~1:35) for a new voice, `extra` (diphthongs ai/ou/ay, 10 lines, ~0:42) added later to the same voice from My voices. Together they cover every sound the voice styles ask for. `algemeen`/`vemmo` stay only so older voices and uploads keep working. Vowels with the same `VSPEC` (a=ah, i=ee, u=oo, ay=ei) count as the same sound in `pickGrain`. More optional rounds (2026-10-26), added from My voices like `extra`: `bloopa` (11 lines: the clusters bl pl fl kl kr gr br fr with every vowel, plus dra, dree, hee, heh; label `k` = ''; ~0:41; the first version recorded whole syllables like flohp, voices that have those keep using them), `ends` (9 lines: every vowel with every end sound p b k m n l r, like a CVVC voicebank, label `tail`; ~0:34; `renderSample` plays a syllable without a recorded ending for 60% and cross-fades into the ending, retuned to the end note and matched in loudness (`tailFor`, `tailStart`, `vowelLevel`); `splitChunk` with `vc` moves each cut from the closure of a p or k to the start of the next vowel, so the burst stays with its sound) and `barks` (the 31 barks of Grunts & Barks, one whole sound per line, label `bark`; ~1:21). `pickGrain` uses such a syllable when start and vowel match: the exact ending first, else one of the same kind (`CODA_CLASS`: bib uses bip), else the version without ending (krik uses kri); `plainGrains` keeps them out of everything else; `renderSample` plays a recorded bark whole. Voice flags `extra`/`bloopa`/`ends`/`barks`. Any round recorded into a saved voice replaces only the sounds it brings (`mergeRound`, by label); "Redo basic round" uses that. Line edges: `soundSpan` keeps the soft consonants before the first vowel and the fade after the last (the old 8%-of-peak trim cut the k of a line-initial kah, measured 2026-10-26). A voice without these rounds renders sample-identical (checked against the committed engine).
  - Own voice pitch shift: a PSOLA shift that keeps length and colour was tried (2026-10-26) and removed: Raoul found it buzzy, too long and less cute than the resampled sound. Classic resampling stays, so a voice set far above the recording gets shorter syllables; recording in the character's own pitch is the fix.
  - Own voice pitch: `pitchTrack` follows each syllable's pitch every 10 ms; `renderSample` option `steady` (0–1, slider "Pitch steadiness", `bm.steady`) holds it on the melody. Without it the output is unchanged.
- Variants and characters (2026-10-25): per style, `cur()` is the latest result and `SV()` the variants saved with "+ Save variant" (each keeps its settings; clicking one plays it and restores them, × removes it; session only). "Save as character" stores style, voice, emotion, sliders, variation (`salt`/`take`) and language seed in `localStorage` `bm.chars`; characters show under Voice and in My voices. Keep UI copy short.
- Use in your game (2026-10-26): `site/game.html` (/game, in the sitemap) shows how to load the web module, speak a line, sync syllables and use an exported voice. On the make screen a round "‹/›" button next to Download (name "Use in your game" as aria-label and hover title; `gameCode()` in app.js) opens a dialog with the module call for the current settings: only options that differ from the voice, `seed` = `st.langSeed` for the made-up-language styles, `ownVoice` + the file name Export gives. The tool has no fixed seed, so the code gives the same voice and settings, not the identical take. GitHub icon in the header, "Use in your game · GitHub (MIT)" in every footer. /game: four short steps, Copy inside each code block (`src/game.js`), the AI-assistant prompt folded under "Show prompt" (self-contained API summary); `llms.txt` lists the web module API and every style and voice id. Update both when options, styles or voices change. 404 page: Fern looking for the page, "Hear Fern" plays a line through the real engine (`src/404.js`).
- `docs/art/`: the README pictures. SVG with the site fonts embedded, made by `node docs/art/make-art.cjs` (run it again after changing styles, voices or the critters in app.js); `tool.png` is a screenshot of the tool.
- Studio prepare screen (2026-10-26): one numbered checklist, Microphone → Listen → Practice (optional) → Record; a step ticks off when done (`prepSteps`: mic granted, example played, practice finished) and the first open one is highlighted. Settings fold under Record; the no-mic route is one line at the bottom. The Prepare/Record/Check bar has no numbers so it doesn't compete with the checklist.
- `site/src/app.js` – UI: i18n (EN/NL in `STR`), make screen, voices storage (IndexedDB `babble-machine`/`voices`: the old name is kept on purpose so voices saved earlier stay available), studio (mic, prompter, recorder)
- `addons/babble_engine/` – Godot 4 addon (phase 2, 2026-10-26): `babble_engine.gd`: a GDScript port of engine.js, `BabbleEngine.render(text, options)` with snake_case options (`sample_rate`). Must give the same samples as the web module: same RNGs (`rng` xorshift, `mulberry` for noise), JS rounding (`js_round`), Float32 where JS uses Float32Array. Errors: `push_error` and an empty Dictionary (no exceptions in Godot). Done (2026-10-26): all 16 styles, own voice (`load_voice`, `render_sample`, including the lowpass cache per sound that makes a render depend on earlier ones, same as JS), and `babble_speaker.gd` (`BabbleSpeaker`, an AudioStreamPlayer: renders on WorkerThreadPool, signals `line_started`, `syllable(index, text)` corrected for output latency, `line_finished`; option `babble_seed` because `seed` shadows a built-in) and `demo/demo.tscn` (UI built in demo.gd: style, voice, mood, a mouth that opens per syllable). The voice, intent, anchor, bark and palette tables are generated from engine.js (scratchpad script, not in the repo): change them in engine.js and port by hand. GDScript pitfalls met: lambdas copy locals (append in place), Packed arrays are copy-on-write (assign filter results back), `len` shadows a built-in. Speed: about 15× slower than the web module. `tests/godot.mjs`: 258 cases sample for sample (max difference 1.2e-7) plus a BabbleSpeaker run; headless audio signals syllables ~70 ms early (no output latency there); in the editor with real audio Raoul found sound and mouth timing right (2026-10-26). Download: `.github/workflows/godot-zip.yml` zips `addons/babble_engine` (+ LICENSE) on every `v*` tag and attaches it to the release as `babble-engine-godot.zip` (fixed name, so `releases/latest/download/babble-engine-godot.zip` is always the newest; linked from README, /game, llms.txt; first in 1.3.1). Next: Godot Asset Library listing (Raoul submits).

## Rules
- Don't change synthesis algorithms for visual work.
- UI copy goes through `t()` with keys in both `STR.en` and `STR.nl`.
- One audio player at a time: always play through `pPlay()` / stop with `pStop()`.
- Studio capture runs on the audio thread (`site/src/rec-worklet.js`, AudioWorkletNode); `ScriptProcessorNode` is only a fallback. It dropped and repeated samples on a busy page (crackle, measured 2026-10-25). The mic is taken raw: `echoCancellation`, `noiseSuppression` and `autoGainControl` off. "Your recording" plays dry (straight to `ctx.destination`).
- Own voices only work with engines where `EMETA[e].rec` is true (all voice styles; not Soft Tones or Talking Instruments).
- WAV export: a plain `.wav` Blob download. Inside a claude.ai artifact (`window.claude` present) it goes through the `downloads` capability instead, zipped (that allowlist has zip, not wav).
- Strict CSP (`site/_headers`, enforced since 2026-10-25): no inline `style`/`<script>`/`on…=` in HTML, no requests to other hosts. Setting `el.style.x` from JS is fine. JSON-LD (`application/ld+json`) is allowed.
- `site/sitemap.xml` lists every public page; a page goes online only when its integration exists.

## Run / test
- Serve `site/` locally: `npx wrangler dev` (applies `_headers` and the 404 page) or `python3 -m http.server -d site`, then open http://localhost:8787 or :8000 (microphone needs http(s), not file://).
- Build check, no dependencies: `node tests/check.mjs` (STR keys EN = NL, banned writing patterns in STR and in the style and voice descriptions in app.js and engine.js, links, sitemap, strict-CSP readiness, headers).
- Godot parity: `GODOT=<path to Godot console exe> node tests/godot.mjs` renders the same lines in a temporary Godot project and the web module and compares sample by sample (`tests/godot/runner.gd`).
- Engine check: `node tests/engine.mjs` (every voice renders without NaN, syllable times in order, same seed same sound, clear errors for bad options, valid WAV, `babble.mjs` exports, version = `package.json`). Both: `npm test`.
- Browser tests (Playwright, Chromium with a fake microphone): `tests/make_screen.py`, `tests/studio.py`. **Out of date** (2026-10-25): they target an older UI (`#voiceSel`, `brabbel.html`, `pw.py`) and a single-file `t2.html`; rewrite them against `site/` via a local server.
- The fake microphone is a test tone, not a voice: real voice recording still needs a manual check.
